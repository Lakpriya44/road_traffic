What is happening on the network

How the server decides

  1. Each junction sends its queue every 3 s by UDP. A lost packet does not matter, the next one replaces it.
  2. The server gives every approach a demand score: vehicles + 2 x queue + waiting time / 10.
  3. If the next junction is already jammed (over 20 queued), the score drops, so we do not push more cars into it.
  4. The highest score gets green for 8 to 25 s. Commands travel by TCP so they are never lost.
  5. Emergency vehicles go first, then pedestrians, then normal traffic.
