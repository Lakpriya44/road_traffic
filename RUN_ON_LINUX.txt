Optional Linux terminal run (Eclipse remains the required development IDE).

From the SmartGrid_Eclipse folder:

    mkdir -p bin
    javac -encoding UTF-8 -d bin src/smartgrid/*.java

Terminal 1 - server on Laptop 1:

    java -cp bin smartgrid.TrafficCenter

Terminal 2 - J01 on Laptop 1:

    java -cp bin smartgrid.JunctionClient J01 127.0.0.1

Terminal 3 - J02 on Laptop 2:

    java -cp bin smartgrid.JunctionClient J02 SERVER_LAN_IP

Terminal 4 - J03 on Laptop 3:

    java -cp bin smartgrid.JunctionClient J03 SERVER_LAN_IP

Replace SERVER_LAN_IP with Laptop 1's IPv4 address (run hostname -I on Laptop 1).
All laptops must be on the same LAN/Wi-Fi. Allow TCP 6655 and UDP 4442 on Laptop 1.

Dashboard: after starting the server, open http://localhost:8082 (or
http://SERVER_LAN_IP:8082 from another laptop). Start the server from the
SmartGrid_Eclipse folder so web/dashboard.html is found.
